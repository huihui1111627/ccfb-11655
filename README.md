# lorasim — LoRa 蜂场网络离散事件仿真器与服务端

面向连锁蜂场 LoRa 物联网的网络仿真器：几百个称重 / 温湿度节点经 LoRa 上报，
仿真器精确建模空中时间、法规占空比、同频冲突与捕获、准正交扩频因子、A 类
接收窗口、网关解调容量、服务端 ADR 与节点 ADR 自愈，并估算电池寿命。
附带一个网络服务端和可视化看板。

## 目录结构

```
internal/
  phy/       物理层：精确空中时间、EU868 频段与占空比、灵敏度
  scenario/  确定性场景生成：节点分布、上报规律、手工固定 SF 分档
  sim/       离散事件引擎：冲突/捕获、占空比、Class A、ADR、电池、报告
  web/       HTTP 服务 + embed 看板（节点地图/信道时间线/SF/丢包/电池）
cmd/
  lorasim/   命令行：固定 SF vs ADR 对比，输出 JSON 与摘要
  loradash/  看板服务端
```

## 快速开始

```bash
# 命令行对比（默认 300 节点、6 小时）
go run ./cmd/lorasim -seed 20261119 -nodes 300 -hours 24 -out result.json

# 看板（http://localhost:8080）
go run ./cmd/loradash -addr :8080 -nodes 300 -hours 6
```

看板包含五块：节点地图（颜色为当前 SF，可点节点看详情）、信道占用时间线
（每分钟一桶，虚线为该子频段法规占空比上限）、扩频因子分布、丢包原因、
电池寿命分布，外加固定 SF 与 ADR 的对比表。页面可改种子 / 节点数 / 时长后
重新仿真。

## 建模要点与需求对应

1. **精确空中时间**：Semtech/SX1276 公式，输入 SF、带宽、编码率、前导码长度
   与低速优化标志（LDRO，按 T_sym > 16 ms 自动判定）。测试向量与官方
   Semtech / TTN 计算器对齐（如 SF9/125kHz/23 字节 = 107.520 ms），见
   `internal/phy/airtime_test.go`。
2. **占空比关断时间**：每个子频段按法规限额（g1=1%、g2/g4=0.1%、g3=10%），
   发送后关闭时间 = ToA × (1/D − 1)，节点在可用时刻前不能再发该子频段；
   被关断的帧延迟重发，单独计入 `dcBlocked`，不算空中丢包。
3. **冲突与捕获**：同信道同 SF 重叠时，最强信号 SIR 超过捕获门限（默认 3 dB）
   则捕获成功、弱者丢包；接近等强则双双失败。不同 SF 按准正交处理，仅当
   干扰强到越过 −6 dB SIR 门限才破坏接收。
4. **服务端 ADR**：保留最近 20 帧信噪比余量，取**最差**余量（而非平均），
   相对目标余量换算成 3 dB 步进；先降 SF 缩短空中时间，再降发射功率省电；
   反向先恢复功率再升 SF。每 16 帧无下行时发保活 ADR/ACK。
5. **节点 ADR 自愈**：长时间收不到下行（默认 48 帧）先拉满功率并升一档 SF，
   之后每 24 帧继续升 SF 直到 SF12。
6. **Class A 窗口**：RX1 在上行结束 +1 s、同信道同速率；RX2 在 +2 s、
   869.525 MHz/SF12。网关半双工，下行必须在窗口打开时刻可发，并预检占空比
   与在途上行干扰；RX1 成功则关闭 RX2。
7. **解调容量**：网关每 SF 解调路数与总路数有限（默认每 SF 1~2 路、总计 8），
   超出记 `demodulator_full`。
8. **电池估算**：按发射（按功率分档电流）、接收、睡眠三态电流 × 时长累计
   mAh，外加每包 MCU/传感能耗，再按 8000 mAh 电池外推寿命。

## 确定性保证

所有随机数来自带种子的 PCG（`math/rand/v2`），主生成器决定场景，每个节点
另有独立子流决定信道选择与快衰落；事件队列按 (时间, 全局序列号) 排序，不
依赖 goroutine 调度或墙上时钟。`sim.Compare` 内部把固定 SF 与 ADR 各跑两遍并
做 JSON 字节比对，结果里的 `determinism` 字段与页面角标直接给出结论。
命令行也可跨进程验证：

```bash
go run ./cmd/lorasim -seed 1 -out a.json
go run ./cmd/lorasim -seed 1 -out b.json
cmp a.json b.json   # 字节级一致
```

## HTTP API

- `GET  /api/comparison`：当前完整对比报告
- `POST /api/rerun`：body `{"seed":..,"nodes":..,"hours":..}` 重新仿真
- `GET  /api/health`：健康检查
